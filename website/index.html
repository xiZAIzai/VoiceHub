Features

转写不是壁垒，分发才是

转写交给成熟引擎完成；VoiceHub 是你的语音控制台——一台主机调度全部设备，把每句话送到该去的地方，全程不需要打开任何窗口。

多端分发核心创新

把一台桌面主机变成全设备的语音控制台：UDP 心跳自动发现局域网设备，零配置组网；台式机直写剪贴板，笔记本 / 平板（含 Termux）接收端收文即自动粘贴。从此告别设备间来回切换、重复输入。

双引擎自动分流

检测到「闪电说」在线时自动交给它，不可用（如 openKylin 渲染异常）时无缝回退内置引擎。设置页一键切换，无需改配置文件。

AI 润色四模式

关闭 / 精炼 / 结构化 / 自定义，DeepSeek 等多家模型厂商预设可选，转写原文与润色结果双双落库可对照。

开源可自控转写内核

转写链路完全开源、厂商随时可换：火山豆包流式直连，或任意 OpenAI 兼容端点（硅基流动 / Groq / 本地 Whisper），适配你的网络与预算，不锁死任何一家。

波形悬浮窗

AGC 自增益实时波形，录音 / 识别双阶段动画，可拖拽、光标跟随。键帽样式直显当前真实热键，再按一次即停。

Web 仪表盘

浏览器打开 127.0.0.1:8765：热键一键注册、录音参数、VAD 静默停止、引擎切换、API 凭证自助填写、历史记录全可视化。

How it works

四步，从开口到落地

一台控制台静默调度，全程无需打开任何窗口。

STEP 1

按热键开口说

全局热键触发录音，悬浮波形窗实时反馈；再按一次或静默超时自动结束。

STEP 2

云端流式转写

音频分片流式上传火山豆包 ASR，边录边传，说完几乎无需等待。

STEP 3

AI 润色（可选）

DeepSeek 按所选模式整理口语：精炼、结构化模板或你的自定义提示词。

STEP 4

一键分发到多端

结果直进台式机剪贴板；按目标热键推送，笔记本、平板接收端自动粘贴——全程无需手动中转，这是一般转写工具给不了的。

Dual Engine

双引擎，互为备份

内置内核保证开箱即用，闪电说在线时自动让位——总有一条路能到达。

内置引擎 · Builtin

火山豆包 ASR 直连

VoiceHub 自建的转写内核：WebSocket v3 流式协议直连豆包大模型 ASR，不依赖任何第三方客户端。只需在设置页填入自己的 API 凭证（支持自助填写，脱敏保存），任何平台都能用——包括闪电说无法运行的 openKylin 等 Linux 发行版。

兼容引擎 · 闪电说

闪电说（已装即用）

已安装 闪电说（本地 AI 离线语音输入法，支持 Windows / macOS）？VoiceHub 会监听它的剪贴板输出并接管分发路由，你原有的使用习惯完全不变。引擎检测失败或手动选择时自动切回内置内核，转写永不中断。

分流逻辑：配置指定谁就用谁；未指定且检测到闪电说在线 → 闪电说优先，否则自动切换到开源可自控内核。

致谢：闪电说（shandianshuo.cn，前身为「代体 Daiti」）是独立优秀产品，与 VoiceHub 无隶属关系； VoiceHub 作为其兼容分发层，让同一套语音输入流程延伸到 Linux 与多设备场景。

Privacy

密钥与数据，都留在你手里

VoiceHub 是纯本地守护进程：没有账号体系，没有遥测，没有云中转。

🔐 凭证只存本机

API Key 仅写入本机 config.local.json（权限 600，已被 gitignore），永不上传、永不入库；也可用环境变量注入。

🙈 仪表盘脱敏展示

设置页只显示密钥尾 4 位，接口永远不回传完整 Key，旁人瞄一眼屏幕也不怕。

💾 历史本地落库

全部转写记录存本机 SQLite，随时可查、随时可迁；音频仅用于当次转写，不留存。
