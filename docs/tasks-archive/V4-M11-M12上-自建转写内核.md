# V4 归档：自建转写内核 M11 + M12-①（2026-08-25 ~ 08-27）

> 主文件只留结论清单，过程记录沉淀于此。要素全景见 PLAN.md「V4」段与 ADR-9。

## 一、Provider spike 与鉴权攻防（M11-①）

- 首测方向 OpenAI 兼容端点被证伪：豆包 ASR 实为 openspeech **WS v3 二进制协议**
  （header 4B + gzip JSON full request + raw PCM 分块 + 末包负包 flags=0b0010）。
- 端点矩阵实测：`sauc/bigmodel`（双向基础版）对 seedasr 资源返回 not allowed；
  **nostream / async 两端点可用**（与闪电说二进制硬编码完全一致——豆包 2.0 只开放
  这两个模式）。默认 nostream（收尾统一返回，准确率优先）。
- 鉴权双方案定案：
  - 新版控制台：`X-Api-Key` 单头。用户提供过一把 158 位方舟系签名 token（内嵌
    Key ID `Hxvi2oMu…`），在 Ark 推理端点与全部语音网关均 Invalid → 判定失效弃用。
  - **旧版控制台（最终生效）**：数字 APP ID（X-Api-App-Key）+ Access Token
    （X-Api-Access-Key）双头；Secret Key 属另一套 REST HMAC 体系，WS 不需要。
    用户找回三件套后探针全链路打通（握手/分块/最终帧），真服务端 duration 对账一致。
- 字体之外的副产品：诊断出 kylin-wlcom 下 `xdotool --window` 定向键不生效等约束。

## 二、M11 主体交付（代码+实机）

- `voicehub/dictation/` 五件套：vad（纯逻辑三停条件）/ recorder（sounddevice +
  **arecord 子进程回退**，免 PortAudio 打包负担）/ asr_client（帧编解码纯函数，
  连接可注入）/ engine（会话令牌状态机）/ overlay（后述）。
- orchestrator.route_direct 直通路由：粘滞目标 → default_target → 首个 local；
  local 投递 = 剪贴板中转（deliver_local 语义入 Router）；落库 source=builtin。
- 触发三通道：托盘菜单（动态标签+图标变红）、UKUI 系统快捷键（gsettings 代写
  custom<N> 槽位 + desktop 文件 Exec，守护重启即枚举生效）、内部 pynput 兜底键
  （注册了系统快捷键时自动停用防双触发）。
- 关键事故修复记录：
  - VAD 静音计数跨会话残留 → 第二次听写秒停（reset() 回归）。
  - xclip 写剪贴板 fork 守护持管道，capture_output 误报失败（DEVNULL 解决）。
  - ASR 客户端只发不读 → 长语音 socket 死锁无结果；改边发边排空 + 取消帧上限。
  - smoke 清理 pkill 匹配过宽误杀用户实例（锚定冒烟目录修复）。
  - FUSE 僵死事故：pkill 强杀运行中 AppImage 致挂载 D 态（ps 都挂死），只能
    重启恢复；确立重部署纪律=托盘优雅退出（DBus Event id=90）。

## 三、M12-① 润色（LLM 后处理）

- 四模式：off（默认原文直出）/ light（轻整理）/ structured（结构化整理，
  prompt 为用户提供版本原样内置）/ custom；OpenAI 兼容 chat/completions。
- 铁律：润色失败一律降级原文继续路由（不挡上屏）；raw_text 落 DB 专用列，
  仪表盘最近转写展示原文对照行。
- 提速两刀：deepseek-v4-flash 关 thinking（思考时延抖动秒级→稳定低位）+
  ASR nostream 大块快发（10s 音频上传 4.7s→2.2s）。

## 四、悬浮框 UI 攻坚史

- v1 中文标题乱码两轮（写死字体族 / fc-match+PIL 位图均不稳，打包环境另缺
  PIL.ImageTk 使位图静默失败字全无）→ **定案英文 ASCII 标题**，构造性免疫。
- 波形「不动」根因=麦克风电平低（说话 RMS~0.02）线性画法仅 3px → 滚动峰值
  AGC 归一化（衰减 0.5%/块）。
- 「识别期满屏红柱」= 动画值误入 AGC 域 → 绘制按阶段分流（listen 电平域 /
  processing 高斯光斑扫动）。
- 键帽标题显示真实热键：来源优先 UKUI 注册绑定（accel_to_display 转换）>
  内部 trigger_key；双层矩形模拟键盘立体感（左上亮边右下阴影）。
- 「灰白残框」三连根因：元组赋值序 UnboundLocalError 杀 tk 线程（窗口已映射
  未进主循环）/ 引擎线程直调 root.quit 触发 Tcl_AsyncDelete / 反复建毁 Tk 的
  土壤 → **持久线程终局架构**：线程常驻，hide=withdraw、show=deiconify 重定位，
  全部控制命令队列化由 tk 线程自执行，close() 于后端 stop 时收口并在同线程置空
  对象引用（引用计数即时释放 Tcl 资源）。进程退出码 0 回归锁定。

## 五、体验流程定稿（用户验收通过）

Alt+9 → 波形框（AGC 跳动+键帽实时热键+可拖动+跟随鼠标屏）→ 再按或超 5min 上限
手动截断 → 「RECOGNIZING...」扫光陪跑 → 结果落剪贴板（wl-copy+xclip 双写）
+ 通知（结果/原因）→ 用户 Ctrl+V。光标处自动注入经两轮攻坚仍受 wlcom 限制，
用户定案暂缓进 PLAN 后续清单（机制保留 auto_paste 开关）。
