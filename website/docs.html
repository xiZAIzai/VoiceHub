使用文档

从安装到多端分发，以及给自动化脚本用的本地接口。所有配置都有默认值——多数人只需要走完「快速上手」。

01快速上手

主控机（你说话的这台）三步：

  1. 下载并运行主控端（Windows 双击 VoiceHub.exe；Linux chmod +x 后运行 AppImage）——配置与数据自动生成在程序旁边；
  2. 浏览器打开 http://127.0.0.1:8765，进「设置」：选转写引擎、填 API 凭证、（可选）配润色；
  3. 注册听写快捷键，按下说一句，再按一下——文字已在剪贴板，Ctrl+V 即用。

接收端（员工机）：部署 VoiceHubReceiver（Windows zip / Linux AppImage），保持和主控机在同一局域网即可被自动发现。想自定义设备名，编辑它旁边的 config.json。

提示：主控机不需要是最强的电脑——它只负责调度。你的笔记本、迷你主机都可以是指挥台。

02核心概念

概念说明
主控机运行 VoiceHub daemon 的机器：录音、转写、润色、分发都从这里出发，并直写本机剪贴板。
接收端（员工）运行 VoiceHubReceiver 的机器。每 4 秒向局域网 UDP 广播报到（端口 9898），收到推送即写剪贴板并自动粘贴。
目标热键Alt+1/2/3/4 选定分发目标（在设置页绑定）。选定后进入粘滞状态，听写结果自动发往该目标。
双引擎「闪电说」在线时自动优先（剪贴板监听链路）；不可用时无缝回退自建内核。设置页可手动指定。
AI 润色可选的 LLM 后处理：把口语整理成自然句子或结构化文本。仅在自建内核链路生效，失败自动降级原文直出。

03转写引擎与供应商

设置页「听写引擎与录音参数」卡：先选引擎，再选供应商（供应商仅在自建内核下出现），凭证卡会跟随联动，只显示需要填的字段。

引擎：闪电说 vs 自建内核

  • 闪电说：已安装即用，VoiceHub 监听其剪贴板输出并接管分发，你原有习惯完全不变；
  • 自建内核（默认）：VoiceHub 自己录音 → 云端转写 → 直通剪贴板/分发。不依赖任何第三方客户端，支持 AI 润色——新装用户填好 Key 即可用。

04AI 润色与模型厂商可选

润色把口述原稿整理成「能直接用」的文字。四种模式：关闭（原文直出，零延迟）/ 轻整理（口语短句 → 自然表达）/ 结构化整理（长口述 → 主题分块的下游喂料）/ 自定义（填你自己的 prompt）。

05多端分发

  1. 在员工机上运行接收端；主控机设置页「目标设备」里核对其热键（默认 Alt+1/2/3/4）与名称；
  2. 同一局域网内自动发现（UDP 9898），无需手动填 IP；特殊网络下可在目标里写死端点 http://IP:5050/paste；
  3. 使用：按 Alt+N 选定目标（粘滞 30 秒，可在设置页调），然后正常听写——结果自动发给该目标并自动粘贴。
员工命名：把接收端叫「员工一号」「员工二号」只是习惯——任何名字都可以，热键和名字都在接收端旁边的 config.json 里改。

06听写快捷键

  • Linux（UKUI / openKylin）：设置页「一键注册」写入系统自定义快捷键（等效控制中心手动添加），任何界面下生效；系统重启后若失效，回设置页重注册一次即可；
  • Windows：内置全局热键（默认 Ctrl+Alt+V，可在配置中改）；
  • 监听中屏幕有波形悬浮窗：再按一次快捷键或说完静音即结束；悬浮窗可拖动，键帽直显当前真实热键。

08本地接口参考

主控机与接收端都提供本地 HTTP 接口，方便脚本与自动化接入。

主控机仪表盘（默认 127.0.0.1:8765，仅本机访问）

POST /api/dictate/toggle        # 开始/结束一次听写（系统快捷键内部就是调它）
GET  /api/state                 # 粘滞目标 / 在线设备 / 目标列表（另有 WS /ws 每 2s 推送）
GET  /api/logs?limit=20         # 最近转写记录（含原文与润色对照）
GET  /api/config                # 读配置
PUT  /api/config                # 写配置（JSON，非法字段返回 400）
GET  /api/credentials           # 凭证状态（只回脱敏尾 4 位）
POST /api/credentials           # 写凭证（JSON，只更新提交的非空字段）
GET/POST/DELETE /api/dictate/shortcut   # UKUI 系统快捷键查询/注册/移除

触发脚本示例（任意机器上远程让主控机开始/停止听写）：

curl -s -X POST http://127.0.0.1:8765/api/dictate/toggle

接收端（默认 0.0.0.0:5050）

POST /paste      # body: {"text": "..."} （JSON，UTF-8）→ 写剪贴板并自动粘贴
GET  /health     # 存活探测

示例：把一句话直接发给某台员工机：

curl -s -X POST http://192.168.1.23:5050/paste \
     -H "Content-Type: application/json; charset=utf-8" \
     -d '{"text": "会议改到下午三点"}'

UDP 心跳：接收端每 4 秒向 255.255.255.255:9898 广播 {"svc":"voicehub","name":"...","port":5050}，主控机据此自动发现。

09数据与隐私

  • API Key 只写入程序旁的 config.local.json（权限 600，已被 gitignore），永不上传、不入库；也可用环境变量 VOICEHUB_ASR_API_KEY / VOICEHUB_ASR_APP_KEY / VOICEHUB_ASR_ACCESS_KEY / VOICEHUB_POLISH_API_KEY 注入；
  • 仪表盘凭证卡只显示尾 4 位，接口永不回传完整 Key；
  • 转写历史存本机 voicehub.db（SQLite），程序旁 logs/ 为运行日志；音频仅用于当次转写，不留存；
  • 拷走程序目录即完成迁移（便携式设计）。

10常见问题

按了听写快捷键没反应？

Linux/UKUI：回设置页点一次「一键注册」（系统重启后快捷键枚举会刷新）；或先用托盘菜单「开始听写」验证链路本身是否正常。

识别结果没有自动粘贴到光标处？

默认只进剪贴板（Ctrl+V 上屏）——Wayland 下向其他窗口注入按键不可靠，这是有意的稳定取舍。分发到接收端的文本会由接收端自动粘贴。

转写报 401 / 无结果？

检查凭证卡状态与供应商是否匹配（火山新版 Key 与旧版双头别混用）；确认对应云端服务已开通。OpenAI 兼容供应商注意 base_url 是否带了 /v1。

润色没生效？

三查：模式是否还停在「关闭」；润色 Key 是否已填；引擎是否为自建内核（闪电说链路有它自己的润色）。润色失败时自动降级原文直出，不会挡住上屏。

8765 端口被占用？

设置页「高级设置」改仪表盘端口，重启后用新地址访问。接收端 5050 / 心跳 9898 同理可在配置中调整。

接收端没被自动发现？

确认与主控机同一网段、路由器未隔离 UDP 广播；仍不行就在目标里写死 http://IP:5050/paste。

支持哪些系统？

主控/接收端：Windows x64 与 Linux x86_64（AppImage 自包含，openKylin / Ubuntu / Debian 等通用）。Wayland 建议安装 wl-clipboard。
